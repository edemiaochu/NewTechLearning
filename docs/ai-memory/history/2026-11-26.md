## 决策与原因

- 顶栏是布局容器而不是控件：整条玻璃板让顶部看起来像叠了第二块面板，只保留胶囊玻璃层次更干净。
- **顶栏背景必须透明**：光学材质画在 canvas 上（`z-index: 0`），顶栏 `z-index: 100`。中途把顶栏改成 `--bg-app` 不透明，整条盖住 canvas，胶囊玻璃"消失"；运行时检查确认 `surfaces: 4`、`titlebar` 背景为 `rgba(0,0,0,0)` 后才恢复。该约束已写入 topic。
- 个人工具链同日调整（不在仓库内）：`work-summary` 日报改为按改动规模分档、强制覆盖检查、不写"未提交"；`git-delivery` 默认先走 SSH 443，失败回退代理/直连。
