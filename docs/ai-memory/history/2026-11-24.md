## 决策与原因

- 复用单一 `FeedService` / `allItems()`：正文缓存、已读/收藏/笔记、代理路由、文章 ID 自动复用
- `news` / `newsSection` / `world` 三标记分层：聚合、侧栏、世界要闻互不耦合
- 事件聚合放渲染层（`news.js`）：纯计算、无 IPC、百条/天足够
- 当天不足回退 24h：兼顾北京时间与欧美发布时区
- AI 概览复用 provider 通道但独立 prompt/解析；只发送标题/来源/摘要
- 概览缓存键含新闻指纹 + 模型；自动整理可关，隐私与费用可控
- 全屏/导出复用现有 `reader-overlay` 与 PDF 管线，不新增依赖
