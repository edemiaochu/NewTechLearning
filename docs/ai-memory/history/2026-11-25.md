# 2026-11-25

## 完成

- 工具栏改为工作台结构：品牌 | 导航组（侧栏开关、概览、今日热点、全部资讯）| 弹性空白 | 搜索 | 操作组（刷新、主题、设置）| 窗口控制；组内按钮 32×32、图标 18×18、stroke 2、组内 gap 2px。
- 侧栏可折叠（工具栏开关 / `Ctrl/⌘+B`）并可拖动调宽 200–380px（双击恢复 262px）；状态持久化。
- 主题面板重做：348px、4 列 × 58px 卡片、8 套主题（新增纯黑 `black`、黑灰 `graphite`）。
- 新增玻璃强度滑块（0–100%），只缩放工具栏/胶囊/面板/侧栏/模态等浮层背景。
- 纯黑/黑灰支持灰度 0–20 实时调节；非灰阶主题的灰度行禁用并显示「—」。
- 新增光学材质与光效面板（380px，主题面板左侧）：折射率、厚度、色散、粗糙度、倒角，实时写入 WebGL renderer，可恢复默认。
- 光学背景（柔光 / 标定 / 纯色）从设置移入主题面板，设置页保留并新增玻璃强度滑块。
- 窗口控制（最小化/最大化/关闭）改为无外框图标：去掉每颗按钮的背景、边框与阴影，也不再把窗口控制组注册为 WebGL 玻璃胶囊；hover 仅保留柔和底色，关闭按钮 hover 变红。
- 新增持久化键：`fr.glassAlpha`、`fr.themeGray`、`fr.glassParams`、`fr.sidebarWidth`、`fr.sidebarCollapsed`。

## 决策与原因

- 复用现有 `liquid-glass-optics` 核心，不引入 React；工作台规范只取布局、几何与 token 规则。
- tokens 分三层：主题块只写 `--bg-*-base`，公开 `--bg-*` 在文件末尾用 `color-mix()` 乘以 `--glass-alpha` 派生；保留无 `color-mix` 回退。
- 玻璃强度不作用 WebGL shader 材质（skill 约定），因此主要影响主题面板、阅读器、设置等 CSS 玻璃覆盖层。
- black/graphite 用单一 `--theme-gray` 派生全部表面，主题面板灰度行常驻，避免切换时面板高度跳动。
- 材质面板只暴露当前核心支持的 5 个 `GlassParams` 字段，不伪造不存在的 shader uniform。

## 补充：英文词典（同日）

- 阅读器 `#reader-content` 内双击英文单词弹出词典卡片；只接受单个英文词（`[a-z][a-z'-]*`），短语/数字/中文不触发，画笔开启时不触发。
- 主进程 `lib/dictionary.js` 并行抓取 Cambridge 英英与英汉页面，用 cheerio 提取音标、词性、释义、例句与例句翻译；按词缓存 600 条 / 30 天（`<userData>/dictionary-cache.json`）。
- 英英在 Cambridge 失败时回退 `api.dictionaryapi.dev`（Wiktionary）；英汉缺失或断网时使用内置 ECDICT。
- **Oxford 未接入**：无免费公开 API，官方 Oxford Dictionaries API 需要 Key；且 `oxfordlearnersdictionaries.com/robots.txt` 对 `anthropic-ai` / `Claude-Web` 等 UA 全站 Disallow。Cambridge robots 允许词典页面，但仍保持按需单词查询，不批量抓取。
- 词典卡为 CSS 玻璃覆盖层（`.dict-popover`，z-index 1450），不注册 WebGL 表面；点击外部 / Esc / 滚动阅读区 / 切文章 / 切视图关闭。
- 新增设置「阅读与词典」：开关（`fr.dictionaryOn`）、清除缓存、来源说明。主进程 IPC：`dictionary:lookup`、`dictionary:clear`。
- 内置 **ECDICT 离线英汉**：从 770k 全量中筛出 59,137 个常用词 + 39,047 个词形映射，压成约 2.2MiB 的 `data/ecdict.json.gz`（MIT）；Cambridge 英汉缺失或断网时兜底，支持音标、柯林斯星级、牛津 3000、考试标签与 `running → run` 词形还原；离线结果标记 `offlineOnly`，不写磁盘缓存并提供「联网重查」。生成脚本 `scripts/build-ecdict.js`。
- 验证：`serendipity` 英英/英汉、`run` 多词性 + 例句/例句翻译、`running`、`basswood`（Cambridge 英汉缺失 → ECDICT 补英汉）、不存在词、非法输入；模拟断网验证 ECDICT-only 卡片、徽章与「联网重查」；截图验证选中词位置与排版；设置开关 1 → 0 → 1 正常。
