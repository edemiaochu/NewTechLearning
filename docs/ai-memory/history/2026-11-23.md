## 决策与原因

- 网络从 Node fetch 切 Electron `net.fetch`：Node 不读 Windows 系统代理，导致抓取全部失败。
- 正文缓存落盘而非只放内存：用户重启/断网后仍应能重新打开读过的文章。
- AI 摘要与正文解耦：AI 摘要已持久化，不应因正文抓取失败而消失。
- 阅读器局部刷新：整块重渲染会重复入场动画、重建笔记框，造成闪烁。
- 首页降低 Claude 权重：Claude 专区此前侧栏大卡过强，首页应作为主入口。
- 所有来源默认 auto：直连优先可避开不必要的代理；1.2 秒超时 + 5 分钟主机缓存兼顾流畅。
- 直连探测使用 HEAD：比 GET 轻量；405 视为可达，403/429/5xx 回退代理。
- AI 默认本机 Claude Code 配置：避免重复保存 Key，并自动跟随本机端点/模型。
- 代理 session 一分为二：默认 session 走全局代理，独立 session 强制 direct，避免规则互相干扰。
